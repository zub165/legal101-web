Delete My Data

Last updated: July 8, 2026

Legal101 does not require an account and does not store your personal app data on our servers. Most information is saved locally on your device. You can delete that data at any time using the steps below.

Important: Deleting app data cannot be undone. You may need to reconfigure language, theme, API settings, and saved map selections after deletion.

What data can be deleted?

  • Language preference
  • Theme and appearance settings
  • Optional API provider and API key
  • Saved lawyer finder pin and area-of-interest points
  • Other locally stored app preferences

Option 1: Delete all app data (recommended)

1
iPhone / iPad

Open Settings → General → iPhone Storage → Legal101 → Delete App, then reinstall if needed.

2
Android

Open Settings → Apps → Legal101 → Storage → Clear Data or uninstall the app.

Option 2: Reset settings inside the app

Open Settings in Legal101 and use Reset to Defaults to remove saved preferences without uninstalling the app. To remove API keys and map selections, also clear those fields manually or use device-level app data deletion above.

Option 3: Remove optional API key

If you entered an OpenAI or other API key, open Settings → Legal API Integration, clear the API key field, and save settings.

Server-side data

Legal101 does not maintain user accounts or a personal data profile on our servers. To request deletion of any support correspondence, email us using the address below.

Third-party services

If you used external links (for example Google search, PayPal, or an AI provider configured with your own API key), those services may have separate data retention policies. Please review and manage data directly with those providers.

Need help?

To request data deletion or get help, email info@innovatorsgeneration.com with the subject Data Deletion Request.
